# FlaStore Controle

Protótipo visual simples para um sistema de controle de produtos de uma loja
fictícia.

## Páginas

- `index.html`: painel inicial
- `produtos.html`: listagem principal com tabela e busca
- `cadastro.html`: formulário de cadastro
- `detalhes.html`: visualização e edição de um produto
- `login.html`: tela de entrada do sistema

## Tecnologias

- HTML puro
- CSS puro
- JavaScript puro

## Estrutura

- `css/style.css`: estilos
- `js/script.js`: interações simples
- `img/`: imagens usadas na página

## Como abrir

Abra o arquivo `login.html` diretamente no navegador.

- E-mail: `adm@teste.com`
